# Data folder
- `raw/services_raw.csv`: prototype services. FICTIONAL. `data_origin=synthetic`. Contains 7 deliberately dirty rows to demonstrate cleaning/validation.
- `raw/queries_seed.csv`: 24 manually written test queries (English), covering query types clear, vague, synonym, multi-intent, typo, price-aware.
- `processed/`: generated by the pipeline (git-ignored): cleaned, validated, rejected, nlp_ready, report.
Regenerate raw data with `python -m scripts.generate_seed_data`.
No public dataset is used yet. If one is added later, record its name, URL and licence here and in `docs/dataset_candidates.md`, and mark rows `public` or `hybrid`.
